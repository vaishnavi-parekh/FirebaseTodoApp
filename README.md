# Firebase To-Do App 📱

An Android task management application developed using **Kotlin, Jetpack Compose, and Firebase Realtime Database**. This app allows users to create tasks, assign priorities, edit task details, and delete completed or unwanted tasks.

## ✨ Features

- Add and view tasks
- Assign High, Medium, or Low priority
- Automatically sort tasks by priority
- Edit task descriptions and priorities
- Delete tasks using a swipe gesture
- Store task data in Firebase Realtime Database
- Anonymous authentication using Firebase Authentication

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Firebase Authentication
- Firebase Realtime Database

## ⚙️ Setup

1. Clone this repository.
2. Open the project in Android Studio.
3. Add your own `google-services.json` file inside the `app` folder.
4. Enable Anonymous Authentication in Firebase.
5. Configure Firebase Realtime Database security rules.
6. Sync Gradle and run the application.
